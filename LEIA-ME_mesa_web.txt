SUSSURROS · MESA ONLINE (regras v0.4)
=====================================

Mesa própria, no navegador, para jogar Sussurros com 3 a 6 pessoas. Substitui o Screentop.
É um site estático (HTML, CSS e JavaScript puro, sem build e sem servidor próprio).
A conexão entre os jogadores é peer-to-peer (WebRTC) com PeerJS. A voz fica no Discord.

É uma mesa "sandbox assistida": ela embaralha, compra, esconde e mostra as cartas certas para
as pessoas certas, mas NÃO aplica as regras sozinha (quem anda quanto, quem perde quanto etc.).
Os jogadores fazem isso, como na mesa física.

NOVO: "PALHAÇO COM IA" (módulo opcional, ligado por padrão). O Palhaço anda sozinho pelas portas no
fim de cada rodada, cobra pedágio em moedas, fala num balão com sino, passa clipes curtos, revela
Eventos e faz propostas secretas. Não usa API paga nem LLM: é um bot heurístico com personalidade que
roda no navegador do host (js/palhaco.js). Detalhes na seção 3b.

NOVO (22/10): TURNOS, CUSTO DE COMPRA E AJUDA. A mesa agora tem vez de cada jogador (faixa "Vez de Ana
(O Médico)", botão "Passar a vez", rodada que avança sozinha), mostra o que cada compra "custou" pela regra
(carta voando do baralho para a mão + aviso flutuante + "Seus últimos gastos"), tem o botão "? Como jogar",
um tour guiado e um nível de experiência por jogador (Iniciante, Intermediário, Veterano). Seção 3c.

Endereço publicado: https://mesaweb-five.vercel.app/ (deploy automático da Vercel a cada push na
branch main do repositório MenesesBuzzi/Mesa_Web).

1. RODAR NO SEU COMPUTADOR
-----------------------------------------------------------------------------

Precisa de um servidor HTTP qualquer (abrir o index.html direto com file:// não funciona,
porque os módulos JavaScript exigem http).

   cd mesa_web
   python3 -m http.server 8080
   (ou:  npx serve .   ou a extensão "Live Server" do VS Code)

Abra http://localhost:8080 . Para testar sozinho, abra a mesma página em outra janela
anônima (ou outro navegador), crie a sala numa e entre com o código na outra.
Precisa de internet mesmo rodando local: a sinalização usa o servidor público do PeerJS.

Testes automáticos (opcionais):
   node testes/protocolo.test.mjs        -> testa motor + privacidade sem rede (só Node 18+)
   node testes/palhaco.test.mjs          -> Palhaço com IA: grafo de portas, 400 rodadas automáticas,
                                            pedágio/moedas, as 12 propostas aceitas e recusadas e
                                            privacidade das propostas (sem rede)
   node testes/turnos.test.mjs           -> turnos: ordem, vez, Passar a vez, contador de passos, rodada
                                            automática, aviso fora da vez, custo da compra e privacidade
                                            de "Seus últimos gastos" (sem rede)
   npm i playwright && npx playwright install chromium
   python3 -m http.server 8080 &
   node testes/e2e_playwright.mjs        -> 1 host + 3 convidados em Chromium headless,
                                            rede real; confere que nada secreto vaza,
                                            testa nível/tour (cada tela vê só o seu),
                                            turnos e custo, e refaz as capturas em capturas/

2. PUBLICAR NO GITHUB PAGES (grátis), PASSO A PASSO
-----------------------------------------------------------------------------

1. Crie uma conta em https://github.com (se ainda não tiver).
2. Clique em "New repository". Nome, por exemplo: sussurros-mesa. Deixe "Public".
   (Pages grátis exige repositório público no plano Free.)
3. Envie o conteúdo da pasta mesa_web para a RAIZ do repositório.
   Jeito fácil: na página do repositório, "Add file" > "Upload files" e arraste TUDO que está
   dentro de mesa_web (index.html, css/, js/, assets/ ...). Não precisa enviar testes/ nem
   capturas/ nem ferramentas/, mas não atrapalham. NÃO envie node_modules.
   Jeito git:
      cd mesa_web
      git init && git add . && git commit -m "Mesa Sussurros"
      git branch -M main
      git remote add origin https://github.com/SEU-USUARIO/sussurros-mesa.git
      git push -u origin main
4. No repositório: Settings > Pages > "Build and deployment" > Source: "Deploy from a branch",
   Branch: main, pasta: / (root) > Save.
5. Espere 1 ou 2 minutos. O endereço aparece no topo da página de Pages:
      https://SEU-USUARIO.github.io/sussurros-mesa/
6. Mande esse link para o grupo. Quem cria a sala clica em "Criar sala" e depois em
   "convidar" (topo) para copiar o link com o código (ex.: .../sussurros-mesa/#K7QXA).

Para atualizar depois: envie os arquivos alterados de novo (ou git push). O arquivo .nojekyll
já está incluído para o GitHub servir tudo sem processar.

3. COMO JOGAR NA MESA
-----------------------------------------------------------------------------

- Uma pessoa cria a sala (vira o HOST). Os outros entram com o código ou o link, e um apelido.
- Cada um escolhe um Hóspede. O host clica em "Iniciar partida": as 11 Fichas de Sala são
  embaralhadas e postas nos círculos FICHA, os baralhos são embaralhados, cada um recebe
  3 Dicas, todos começam com 80% no Disco e no Saguão, Relógio no 1.
- Planta: arraste para mover a vista, roda do mouse ou pinça para zoom, botões + − ⤢.
  Arraste o SEU peão (o de anel dourado tracejado). O Palhaço qualquer um arrasta.
- Fichas de Sala: toque na Ficha do cômodo onde seu peão está > "Olhar em segredo".
  Depois: "Deixar virada para cima" ou, se for Chave, "Pegar a Chave" (fica à vista).
  A Médium tem o botão extra para olhar a Ficha de qualquer cômodo.
- Aba MÃO: sua ficha (toque para ampliar), "Usei a habilidade" (vira a ficha USADA),
  Corrente de Laço, botões de compra (Evento, Dica, Distorção, Laço, Pacto, Sanidade do
  seu nível e dos 5 níveis), sua mão (toque numa carta: revelar a todos, descartar sem
  mostrar, dar como Dica) e as Dicas que você recebeu (Seguir = revela a todos; Ignorar =
  descarta sem revelar).
- Aba DISCO: sua sanidade secreta (0 a 100, passos de 5), nível, "Estou Tomado"
  (marcado sozinho ao comprar um Pacto), Fichas que você olhou e Dicas que você deu.
- Aba MESA: última carta revelada, último dado, todos os jogadores (nível da última carta
  de Sanidade, Dicas na mão, Dicas recebidas, Chaves, Corrente, cartas à vista), "Dar Dica",
  e a contagem dos baralhos.
- Aba LOG: tudo o que aconteceu. Linhas "só você" são privadas.
- Topo: Relógio 1–12 (+ Rodada / −, só o host), Dado (à vista), Dado escondido (só você vê o resultado;
  serve para Delírio e oráculo falso), Noite, e o menu ☰.
- NOITE: todos veem a tela escura. Quem está marcado como Tomado recebe em segredo
  1 carta de Sanidade 10% e vê a planta por baixo para mover o Palhaço 1 cômodo.
  "Amanhecer" libera depois de 7 segundos (para ninguém deduzir nada pela pressa).
- Moedas: com o Pedágio ligado, cada um começa com 5 moedas, à vista (no peão e na aba Mesa).
- Fim: menu ☰ > "Abrir Discos" (só o host) mostra a sanidade e quem estava Tomado.
  "Nova partida" recomeça com as mesmas pessoas.
- Se a internet de um convidado cair, ele volta sozinho (ou recarregando a página com o
  mesmo link: o navegador lembra o lugar dele). Se o HOST recarregar, ele pode usar
  "Retomar sala XXXXX" na tela inicial: o estado fica salvo no navegador dele.

3b. PALHAÇO COM IA (módulo opcional; regras.md, "Módulo opcional: Palhaço Automático e Moedas")
-----------------------------------------------------------------------------

Interruptores (só o host, aba MESA > "O Palhaço"): "Palhaço automático" e "Pedágio e moedas",
os dois ligados por padrão. Com o automático desligado, o Palhaço volta ao modo manual (arrastar).

- Movimento: a cada "+ Rodada" o Palhaço anda 1 ou 2 cômodos pelo grafo de portas e escadas da
  planta fixa (o mesmo de mapa/tabuleiro.py: Palco só pelo Camarim, Porão só pela Cozinha etc.).
  Personalidade: ~54% vai atrás do mais próximo, ~18% de quem tem mais moedas, ~16% de quem está
  sozinho, ~12% faz um despiste para um cômodo vizinho. Se entra num cômodo ocupado, para ali.
  O peão desliza pelas portas na tela de todos (com um pulinho de sapato grande).
- Pedágio: quando o Palhaço entra no cômodo de alguém (sozinho, arrastado ou na Noite, cobrado ao
  amanhecer) ou alguém entra no dele: paga 1 moeda (sem moedas: -15% de sanidade), vai para um cômodo
  sorteado diferente (nunca o Palco) e rola o Dado do Olho: fechado = -10%; aberto = 1 Distorção ou
  1 Laço com Corrente (sorteado). O Disco é ajustado sozinho; o log público mostra tudo menos a
  porcentagem (ela aparece só no log "só você" da vítima).
- Falas: 62 falas curtas (início, perseguir, pegar, errar, despiste, Eventos, propostas, fim) num
  balão sobre a tela de todos, com um sino sintetizado em WebAudio (sem arquivo de áudio). O som só
  toca depois do primeiro clique na página (regra dos navegadores).
- Clipes: 7 clipes mudos de 4 a 5 s (acenando, malabarismo, rindo, chapéu, sumindo, psiu, você),
  640x360, WebM VP9 + MP4 H.264 de reserva, 50 a 125 KB cada (assets/palhaco/clipes/). Tocam no
  início da partida, quando o Palhaço pega alguém e a cada 2 ou 3 rodadas. Cada um pode "Pular".
  Gerados por P/video/clipes_mesa.py a partir das poses de P/video/poses (mesmo estilo de cenas.py).
- Eventos: em ~1/3 das rodadas o Palhaço compra um Evento, que vai para o descarte e aparece para
  todos com uma fala. Leiam e apliquem (a mesa não aplica o texto do Evento).
- Propostas: em ~35% das rodadas ele sussurra uma de 12 ofertas a alguém (quem tem menos sanidade,
  mais moedas ou alguém ao acaso, desde que a oferta seja possível). Só essa pessoa vê o texto e os
  botões Aceitar/Recusar; o efeito é aplicado sozinho. O log público diz só "O Palhaço sussurrou algo
  para X" e depois "X ACEITOU/recusou o sussurro do Palhaço". Sem resposta até a rodada seguinte, a
  oferta "se perde no escuro". Efeitos à vista (moedas, Corrente, mudança de cômodo) continuam à vista.
- Tudo é decidido no host com o mesmo sorteio do resto da mesa; os convidados só recebem o "show"
  (lista de passos públicos: fala, trajeto, dado, clipe, Evento) e tocam na mesma ordem.

3c. TURNOS, CUSTO DE COMPRA E AJUDA (22/10)
-----------------------------------------------------------------------------

O QUE A REGRA DIZ (regras.md, seção 6 "O turno" e seção 4):
  - Na sua vez, nesta ordem: 1) Sussurro, opcional (1 Dica); 2) Movimento, até 2 Salas, OU descansar (+5%);
    3) Explorar (olhar a Ficha do cômodo; Armadilha = 1 Laço); 4) Evento (compre 1); 5) Nível (compre 1
    Sanidade do seu nível; 75%/50% compram 1 Distorção no fim da vez); 6) Reabastecer (Dicas até 3).
    "Quando todos jogarem, avance o Relógio em 1." Depois vem a Noite.
  - A regra NÃO fala em "pontos de ação" nem cobra nada para comprar: comprar carta não custa sanidade,
    moedas nem ação. Cada compra é um passo da vez. O que tira sanidade é o efeito da carta (alternativa da
    Sanidade, Evento, Laço), a fobia, a Dica falsa seguida e o pedágio do Palhaço (1 moeda; sem moedas, 15%).
  Por isso o "contador" da mesa não é de ações gastas: mostra os passos da vez (Dica 0/1, Mover 0/2,
  Ficha, Evento 0/1, Sanidade 0/1, Dicas 3/3) e fica vermelho quando passa do que a regra pede.

TURNOS (o host decide tudo; os convidados só veem):
  - Ordem: a de entrada na sala. O host pode marcar "Sortear a ordem dos turnos" no saguão, ou usar
    "Sortear ordem" / "Ordem de entrada" na aba Mesa (só no começo de uma rodada).
  - Faixa abaixo do topo, para todos: "Vez de Ana (O Médico) · Rodada 3 · 2º de 4 · depois: Beto" e os
    passos já feitos. O peão de quem está na vez brilha e o nome fica dourado. Na aba Mesa, "Ordem dos turnos".
  - "Passar a vez" (grande) aparece só para quem está na vez e para o host ("Passar a vez de Ana", para quem
    caiu ou esqueceu). Quem está na vez também tem "Descansar" (+5%, no lugar do Movimento).
  - Quando o último passa, a rodada avança sozinha: é a mesma lógica do "+ Rodada" (Relógio anda, Palhaço
    automático age) e a vez volta ao primeiro. O log lembra que é hora da Noite. "+ Rodada" e "−" manuais
    continuam, agora só para o host.
  - Ao chegar a sua vez: aviso grande "É a sua vez!", som curto (WebAudio) e vibração no celular.
  - Fora da vez a mesa continua livre (Dicas sussurradas, Seguir/Ignorar, Corrente, Dado). Se alguém compra
    ou move o próprio peão fora da vez, a mesa deixa (é sandbox), mostra um aviso leve e o log público marca
    "(fora da vez)". Pacto e Sanidade 10% nunca ganham essa marca (seriam pista de Tomado).
  - Tudo vai para o log: ordem, quem passou e o que fez ("Fez: andou 2 Salas, 1 Evento, 1 Sanidade"),
    rodada automática, descanso, host passando por alguém.

CUSTO AO PUXAR CARTA (só quem comprou vê):
  - A carta (verso do baralho) voa do baralho para a mão; a aba Mão pisca.
  - Aviso flutuante com o que mudou: "Grátis nesta vez" / "1ª compra da vez" / "Acima da regra: 2º Evento
    nesta vez" / "Fora da sua vez", o passo usado ("Passo 4 (Evento): 1/1 usado"), lembretes (nível certo,
    Dicas 4/3, máximo de Distorções) e "Baralho Evento: 26 restantes". Pacto e Sanidade 10% não mostram
    quantas sobram (contar revelaria Tomados).
  - O Disco (aba) e as moedas (no peão e na aba Mesa) piscam quando mudam. Perdas/ganhos SEUS (pedágio,
    proposta, descanso) aparecem num aviso "−1 moeda" / "−10% sanidade · só você vê".
  - "Seus últimos gastos" na aba Mão: compras, pedágios, propostas aceitas, descanso e ajustes do Disco.
    Vem só na visão do dono (v.eu.gastos); nunca na parte pública.

AJUDA:
  - Botão "? Como jogar" no topo (sempre visível; na tela inicial, o link "Como jogar?"): "Regras em
    1 minuto" (objetivo, a vez, sanidade e níveis, Tomados e Pactos, Palhaço e moedas, Noite, vitória) e
    "Como usar a mesa" (faixa, Mão, Disco, Mesa, Log, + Rodada, Dado, Dado escondido, Noite, Corrente, planta).
  - Tour guiado de 8 balões (faixa da vez, planta, Relógio, Dado/Noite, Mão, Disco, Mesa/Log, botão ?).
    Pode pular, voltar e repetir (menu ☰ > "Repetir o tour guiado" ou no Como jogar). Funciona no celular.
  - NÍVEL DE EXPERIÊNCIA: cada um escolhe no saguão, junto com o Hóspede; fica no localStorage do
    navegador (chave sussurros-nivel) e muda no menu ☰ > "Nível de experiência". Não vai pela rede.
      Iniciante: tour completo quando a partida começa + dicas contextuais (uma vez cada): "Agora mova seu
        peão", "Toque no baralho para comprar", "Terminou? Passe a vez", custo da 1ª compra, 1º pedágio do
        Palhaço, 1ª Noite, 1ª Dica recebida, tentativa fora da vez. Quem não escolher conta como Iniciante.
      Intermediário: 4 balões curtos no início (vez, comprar, passar a vez, Palhaço). Sem dicas contextuais.
      Veterano: nada abre sozinho.
    O tour abre uma vez por sala (sussurros-tour-CÓDIGO). Cada tela tem o seu: não sincroniza.

4. PRIVACIDADE: O QUE CADA UM RECEBE
-----------------------------------------------------------------------------

O navegador do host guarda o estado oficial e manda a cada jogador só a "visão" dele
(função visao() em js/motor.js). Pela rede, nenhum convidado recebe:
  - as cartas da mão dos outros (Dicas com selo, Distorções, Pacto, Sanidade 10% da Noite...);
  - a carta de uma Dica virada para baixo (nem quem recebeu: só vê ao Seguir, e aí todos veem);
  - a sanidade e o "Tomado" dos outros (até Abrir Discos);
  - Fichas de Sala ainda viradas (cada um só recebe as que ele mesmo olhou);
  - o dado escondido dos outros e as linhas "só você" do log deles;
  - o tamanho dos baralhos de Pacto e Sanidade 10% (contar revelaria quem é Tomado);
  - as propostas do Palhaço feitas a outra pessoa (nem o texto, nem a referência) e a sanidade
    resultante de um pedágio.
Todos veem de qual NÍVEL cada um comprou a carta de Sanidade, como manda a regra.
A compra de Pacto não aparece no log público.
  - o histórico "Seus últimos gastos" dos outros (vai só em v.eu.gastos do dono);
  - o nível de experiência e o tour de cada um (ficam só no navegador dele).
Os testes conferem isso: testes/protocolo.test.mjs (379 checagens, com o Palhaço automático ligado),
testes/palhaco.test.mjs (2512 checagens), testes/turnos.test.mjs (193 checagens) e
testes/e2e_playwright.mjs (3999 checagens nas mensagens que de fato chegaram pela rede, 1 host + 3 convidados).
Atenção: escolher quem tem MENOS sanidade para uma proposta dá uma pista fraca (é só uma das três
regras de escolha, e às vezes a oferta nem é possível para essa pessoa).

LIMITAÇÃO IMPORTANTE: o HOST tem tecnicamente o estado inteiro na memória do navegador dele.
Ele não vê nada disso na tela, mas um host que abra as ferramentas de desenvolvedor (F12)
consegue ler tudo, e o estado também fica salvo no localStorage dele. Duas saídas:
  a) o host é um MODERADOR que não joga (marque "Sou moderador" ao criar a sala); ou
  b) o grupo aceita essa limitação e confia no host (como confiar em quem embaralha).
As imagens das cartas são públicas no site (como as cartas da caixa); o segredo é QUAL carta
está com quem, e isso só o host sabe.


-----------------------------------------------------------------------------
5. LIMITAÇÕES E O QUE FICOU DE FORA
-----------------------------------------------------------------------------

- Não é motor de regras: não conta movimento por portas, não aplica fobia, Susto, Capela,
  +10%/−10% das Dicas, Distorção automática por nível nem vitória. Os jogadores aplicam e
  ajustam o Disco. A mesa só lembra (ex.: o botão "Comprar Sanidade do meu nível" escolhe o
  baralho pela sua sanidade; Tomado compra do 25%).
- Palhaço automático: ele não lê o texto dos Eventos nem aplica fobias; o pedágio substitui o Susto
  da regra física (não há os 5% do Susto além do pedágio). Desligando o automático, volta o manual.
- Os clipes são mudos (o sino é sintetizado na hora) e começam quando cada navegador recebe o aviso
  do host: a diferença entre as telas é a da rede (normalmente menos de 1 s).
- Turnos: a mesa registra os passos, mas não obriga a ordem (pode comprar o Evento antes de mover) nem
  bloqueia compra/movimento fora da vez (só avisa). O contador de "Mover" mede pelas portas entre a sala de
  saída e a de chegada de cada arrasto; não sabe se o peão passou por paredes. "Ficha" conta só quando você
  olha a Ficha do seu cômodo. A Noite ainda é chamada à mão (o log lembra).
- Custo: como a regra não cobra nada pela compra, o aviso mostra o passo usado e os limites da regra, e
  não "−1 ação". A perda de sanidade de uma carta de Sanidade continua sendo aplicada à mão no Disco.
- Tour e dicas: textos fixos; se a tela for muito pequena (menos de 360 px de altura livre) o balão cai no
  centro. O som "É a sua vez!" só toca depois do primeiro toque na página (regra dos navegadores).
- Habilidades são só o botão "Usei a habilidade" (exceção: a Médium tem o botão de olhar
  qualquer Ficha). O Radialista, o Contador de Histórias etc. são resolvidos na conversa.
- Delírio: a mesa não inverte o selo nem o texto; use o "Dado escondido" e aplique.
- Chaves: pegar e passar para outro jogador funcionam; não dá para devolver uma Chave a um
  cômodo nem largar no Palco (basta ela estar na frente de quem está no Palco).
- Quando um baralho acaba, o descarte dele é reembaralhado sozinho.
- Se o host fechar a aba, a sala cai para todos (dá para retomar pelo navegador do host).
- Rede: usa o servidor público grátis 0.peerjs.com só para os navegadores se acharem; se ele
  estiver fora do ar, ninguém conecta. Em redes muito fechadas (algumas empresas, 4G com NAT
  simétrico) a conexão direta pode falhar: aí é preciso um servidor TURN (veja js/config.js).
- O tamanho dos baralhos visíveis e a ordem/hora das mensagens não revelam cartas, mas quem
  abrir o F12 sabe que ALGUÉM moveu o Palhaço durante a Noite (não quem) - igual ao físico,
  em que todos veem que ele mudou de lugar.
- Testado em Chromium headless (desktop 1440x900 e celular 390x844). Não testei em Safari/iPhone
  de verdade nem entre redes diferentes (o teste rodou com as abas na mesma máquina).
- 4 cartas de Sanidade ainda falam em girar/trocar Salas (pendência das cartas, não da mesa).

6. ARQUIVOS
-----------------------------------------------------------------------------

index.html ........... página única

js/dados.js .......... baralhos, Hóspedes, coordenadas da planta (GERADO)
js/peerjs.min.js ..... PeerJS 1.5.4 (cópia local, sem depender de CDN)
assets/ .............. imagens leves (cartas, fichas, peões, dado, relógio, personagens, planta) e fontes
assets/palhaco/clipes/ 7 clipes do Palhaço (.webm + .mp4)
ferramentas/gera_dados.py ... regenera js/dados.js a partir de assets/ e dos CSVs
                              (digital/screentop/grades_tts/*.csv: ordem e selo das Dicas)
ferramentas/coords_mansao.py/.json ... coordenadas dos cômodos e círculos FICHA na planta
                              (mesma geometria de mapa/tabuleiro.py e tabuleiro_digital.py)
testes/ .............. teste de protocolo (Node) e teste de ponta a ponta (Playwright)
capturas/ ............ telas do host e dos convidados (desktop e celular)

Protocolo (JSON pelo DataChannel):
  convidado -> host: {t:'entrar', apelido, token} | {t:'acao', pedido, a:{t:'comprar', baralho:'evento'} ...}
  convidado -> host (turnos): {t:'acao', a:{t:'passarVez', seq}} | {t:'descansar'} | host: {t:'ordemTurnos', embaralhar}
  visão (turnos): v.turno = {ordem, vez, daVez, rodada, seq, feito:{dica,salas,descanso,ficha,evento,nivel,dicas,distorcao,laco}}
                  v.eu.gastos = [{t, txt}] (só o dono); resposta da compra: {ok, carta, custo:{titulo, linhas, acima, baralho, restante, foraDaVez}}
  convidado -> host (Palhaço): {t:'acao', a:{t:'respostaProposta', ref, aceitar}} | host: {t:'palhacoConfig', auto, pedagio}
  visão (Palhaço): v.shows = [{seq, passos:[{t:'fala',texto} | {t:'mov',caminho,pegos} | {t:'dado',face}
                   | {t:'video',clipe} | {t:'evento',carta}]}], v.jogadores[].moedas, v.eu.proposta (só o dono)
  host -> convidado: {t:'bemvindo', id, token} | {t:'visao', v} | {t:'pos', alvo, x, y}
                     | {t:'resposta', pedido, ok, erro, carta?} | {t:'expulso'}
